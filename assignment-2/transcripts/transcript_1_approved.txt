To implement a production-grade Token Bucket rate limiter in FastAPI, we must ensure that the state (tokens and last refill time) is managed atomically. Using `asyncio.Lock` per key prevents race conditions during the "read-modify-write" cycle of token consumption.

### Implementation

```python
import asyncio
import time
from typing import Dict, Optional, Callable
from fastapi import Request, Response, status
from starlette.middleware.base import BaseHTTPMiddleware

class TokenBucket:
    def __init__(self, capacity: float, refill_rate: float):
        if capacity <= 0 or refill_rate <= 0:
            raise ValueError("Capacity and refill_rate must be positive.")
        self.capacity = float(capacity)
        self.refill_rate = float(refill_rate)
        self.tokens = float(capacity)
        self.last_refill = time.monotonic()
        self.lock = asyncio.Lock()

    async def consume(self, amount: float = 1.0) -> bool:
        async with self.lock:
            now = time.monotonic()
            elapsed = now - self.last_refill
            
            # Replenish tokens
            self.tokens = min(self.capacity, self.tokens + elapsed * self.refill_rate)
            self.last_refill = now

            if self.tokens >= amount:
                self.tokens -= amount
                return True
            return False

class RateLimitMiddleware(BaseHTTPMiddleware):
    def __init__(self, app, capacity: float = 10.0, refill_rate: float = 1.0):
        super().__init__(app)
        self.buckets: Dict[str, TokenBucket] = {}
        self.capacity = capacity
        self.refill_rate = refill_rate

    async def dispatch(self, request: Request, call_next: Callable) -> Response:
        # Use client IP as the unique key
        client_ip = request.client.host if request.client else "unknown"
        
        if client_ip not in self.buckets:
            self.buckets[client_ip] = TokenBucket(self.capacity, self.refill_rate)
        
        bucket = self.buckets[client_ip]
        if not await bucket.consume(1.0):
            return Response(
                content="Too Many Requests", 
                status_code=status.HTTP_429_TOO_MANY_REQUESTS
            )
        
        return await call_next(request)
```

    async with AsyncClient(transport=ASGITransport(app=app), base_url="http://test") as client:

    async with AsyncClient(transport=ASGITransport(app=app), base_url="http://test") as client:

### Key Engineering Decisions:
1.  **`time.monotonic()`**: Used instead of `time.time()` to ensure the rate limiter is immune to system clock adjustments (NTP syncs), which is critical for distributed systems.
2.  **`asyncio.Lock`**: By placing the lock inside the `TokenBucket` instance, we ensure that concurrent requests from the *same* client are serialized, while requests from *different* clients remain non-blocking relative to each other.
3.  **Memory Management**: In a production environment with millions of unique IPs, you should replace the `self.buckets` dictionary with an `LRUCache` or a Redis-backed implementation to prevent memory exhaustion.
4.  **Granularity**: The `refill_rate` is calculated per second, providing a smooth token replenishment flow.
